# Gambling Kills — Recovery Prototype

A mobile-first, local-first gambling recovery web app focused on interrupting the next gambling decision.

## Core V1 flows
- Urge Mode: 10-minute pause + friction steps
- Break the Chase
- Clear-headed message
- Trusted-person check-in copy
- Protection Centre
- Recovery dashboard
- Relapse flow without streak shaming
- “The Mirror” for repeated “one last bet” thinking

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Privacy
V1 stores recovery information in browser localStorage only. No account, analytics, or server sync is included yet.

## Safety
This is a support tool, not medical care. Do not add gambling tips, odds tools, betting links, operator ads, affiliate links, or casino-style reward mechanics.
